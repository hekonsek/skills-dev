# skill-superpowers-writing-plans-use-skills

When creating implementation plans from design documents Superpowers sometimes forgets to use other skills that provide ADRs, best practices, golden paths, and other relevant guidance. Because of that created implementation plans may miss important considerations and guidance from these other skills.

This skill ensures that Superpowers takes into account guidance from other skills when creating implementation plans, reducing the risk of missing important considerations and best practices.

## Workflow

1. When creating an implementation plan from a design document, Superpowers should first identify relevant skills that provide ADRs, best practices, golden paths, and other guidance.
2. Superpowers should consult these skills to gather the necessary information and recommendations.
3. Superpowers should incorporate the guidance from these skills into the implementation plan.
4. Superpowers should review the implementation plan to ensure that all important considerations and best practices from the consulted skills have been included.

## Verification

To verify that this skill is being followed correctly, check that:
1. Implementation plans created from design documents reference relevant skills that provide ADRs, best practices, golden paths, and other guidance.
2. The guidance from these skills is incorporated into the implementation plan.
3. The implementation plan has been reviewed to ensure that all important considerations and best practices from the consulted skills have been included.
